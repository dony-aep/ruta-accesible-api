# AGENTS.md — Ruta Accesible

Este repositorio mantiene sus instrucciones para agentes de IA en un solo archivo:
**`CLAUDE.md`**, en la raíz.

**Léelo antes de proponer o hacer cualquier cambio.** Contiene:

- cómo identificar con qué cuenta se está trabajando y qué plan tiene asignado esa persona,
  incluido el trato para auditores como el profesor
- el reparto de los seis planes, sus dueños, sus archivos propios y el orden de desbloqueo
- las reglas de los pull requests y de las revisiones entre compañeros
- convenciones de código, manejo de secretos y comandos de verificación

No dupliques reglas en este archivo: si algo cambia, se cambia en `CLAUDE.md`.
